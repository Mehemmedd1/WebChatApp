Web Chat Application💬

A simple web chat application built with Spring Boot, WebSocket, MongoDB, and Docker Compose.

Features✨

Real-time messaging using WebSocket.

Persistent message storage with MongoDB.

Easy setup with Docker Compose.

Technologies Used💻

Spring Boot: Backend framework for creating the chat application.

WebSocket: Real-time, two-way communication between client and server.

MongoDB: Database for storing chat messages and user data.

Docker Compose: Containerized environment for easy deployment.

Setup & Installation🚀

Prerequisites:

Docker & Docker Compose installed on your machine.

Java 17 or higher (for Spring Boot application).

MongoDB running in a Docker container (via Docker Compose).
